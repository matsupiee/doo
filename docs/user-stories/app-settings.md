# 設定画面でアプリの見た目とサインアウトを操作する

> ステータス: 実装済み。画面まわりのみで、API の追加はない。

## ストーリー

doo を使う人として、
プロフィールの右上から設定画面に入り、外観の切り替えとサインアウトをそこで行いたい。
そうすれば、切り替えたい操作がダイアログの中に隠れず、いつも同じ場所から探せる。

## 動作確認の手順

1. `bun run db:seed` でシードを流す。
2. サインインしてプロフィールタブを開く。
   - ヘッダーの右端が歯車のアイコンになっている。ハンバーガーのアイコンは出ない。
   - 登録の入口はホームの ＋ にまとめたので、歯車の左に + のアイコンは並ばない。
3. 歯車を押す。
   - 「設定」というタイトルの画面に移動する。
   - 「設定」の見出しの下に「外観」の行が出る。行の右端に、今のテーマが「ライト」か
     「ダーク」で出る。
   - 「アカウント」の見出しの下に「サインアウト」の行が出る。文字とアイコンは赤い。
   - ヘッダーの戻るでプロフィールに戻る。
4. 「外観」を押す。
   - 「外観」というタイトルの画面に移動する。
   - 「ライト」と「ダーク」が縦に並び、今のテーマの行にチェックが付く。
5. 今と違うテーマを押す。
   - その場でアプリ全体の配色が変わり、チェックが押した行に移る。
   - 戻ると、設定画面の「外観」の右端が選んだテーマの名前に変わっている。
6. 設定画面で「サインアウト」を押す。
   - サインアウトするかを聞く確認のダイアログが出る。
   - 「キャンセル」を押すと設定画面のままで、サインインしたままになる。
   - 「サインアウト」を押すとオンボーディング画面に戻る。
   - → [新規登録かログインかを選ぶ](./onboarding-choose-sign-up-or-sign-in.md)

## データの持ち方

- 設定画面は端末の中の状態だけで動く。テーブルは追加しない。
  - テーマは `contexts/app-theme-context.tsx` が持ち、uniwind に渡す。
  - サインアウトは better-auth のセッションを消し、あわせて tRPC のキャッシュも捨てる。

## 対応するテスト

API を足していないので、この画面を守るサーバー側のテストはない。画面の操作は iOS
シミュレータでの手動確認で担保する。

```bash
bun run check-types
```
