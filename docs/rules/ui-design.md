# 画面の見た目のルール

`apps/native` の画面を書くときに従う。色と形をここに集めておき、
画面ごとに違う角丸や違う灰色が生えないようにする。

## 下地と面

- 画面の下地はうすいライラック（`bg-background`）。ここに白い面と色の面を置く。
- 白い面（`bg-surface`）はフォームと読みもの。角丸は 22px から 26px。
- 色の面はやりたいこと1件を表す。角丸は 26px から 28px。
  - 色は `apps/native/theme/tones.ts` の `toneFor` が ID から決める。
    同じやりたいことはいつも同じ色になるので、一覧を作り直しても色が飛ばない。
  - 色の面の上に置くものは白い面か白いピルにする。色の上に色は置かない。
- 影は `cardShadow` だけを使う。強さを画面ごとに変えない。

## 文字

- 画面の見出しは 28px から 34px の `font-extrabold`。ナビゲーションバーは使わず、
  下地の上に直接置く。
- 一覧の見出しは `SectionTitle`（20px の `font-extrabold`）。罫線は引かない。
- 補足は `text-muted`。色の面の上では `tone.mutedForeground` を使う。
- 色を白い面の上に文字として出すときは `tone.onWhite` を使う。
  黄色やコーラルはそのままだと白の上で読めない。

## 部品

- 丸ボタンは `RoundIconButton`。戻る、追加、進むなど、面の角に置くものはこれに寄せる。
- 小さな情報は `Pill`。タグ、件数、絞り込みのすべてを同じピルで出す。
- 達成1件は `CompletionRow`。左の丸いチェックの色はやりたいことの色に合わせる。
- ボタンは `rounded-full`。主要な操作は高さ 56px（`h-14`）。
- タブバーは `FloatingTabBar`。画面の下に浮かぶピルで、選んでいるタブだけ
  ブランド色の塗りとラベルになる。

## 色を足すとき

色は `global.css` の CSS 変数と `theme/tones.ts` にだけ書く。
画面のファイルに 16進数の色を直接書かない。
