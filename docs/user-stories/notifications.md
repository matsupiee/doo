# 通知で気づく

> ステータス: 仕様のみ。`notification` テーブルはまだスキーマに無い。
> テーブルの追加とマイグレーション生成は別 PR で行う。API・UI はそのあと。

## ストーリー

**ユーザー** として、
**自分に関係することが起きたら気づきたい**。
そうすれば、**自分のやりたいことに乗ってくれた人や、自分を入れてくれた達成を見逃さない**。

## 受け入れ条件

- 通知一覧の画面があり、新しい順に並ぶ。画面の置き場所（タブを増やすか、ホームの
  ヘッダーに出すか）は実装時に決める。
- **未読があるとバッジが出る**。一覧を開くか個別に開くと既読になり、バッジが減る。
- 記録するのは次の3種類。

  | 種別                      | 受け取る人           | きっかけ                                |
  | ------------------------- | -------------------- | --------------------------------------- |
  | `mission_participated`    | やりたいことの作成者 | 誰かがそのやりたいことに参加した        |
  | `completion_participated` | 達成に含められた人   | 自分が共同達成の参加者に入れられた      |
  | `post_reacted`            | 投稿の作者           | 自分の投稿にリアクションが付いた        |

- 通知には **誰が（actor）** と **どこで（やりたいこと / 達成 / 投稿）** が入り、
  タップするとその画面に飛ぶ。
- **自分の操作で自分に通知は作らない**（自分の投稿に自分でリアクションした、
  自分のやりたいことの作成で自分が参加者になった、など）。
- 達成の記録で **自動的に参加者にされた人** にも `completion_participated` が届く。
  知らないうちに参加者一覧に載るので、気づける場所が要る。
- リアクションを外したときは通知を消さない（起きた出来事の記録として残す）。
- 通知の元になったやりたいこと・投稿・達成が消えたら、その通知も消える。
- 送信手段は **アプリ内の通知一覧だけ**。プッシュ通知とメールは範囲外。

## データの持ち方

`notification` テーブルを新設する（1テーブル1ファイルの規約どおり
`packages/db/src/schema/notification.ts`）。

| 列                                            | 用途                                          |
| --------------------------------------------- | --------------------------------------------- |
| `user_id`                                     | 受け取る人。cascade                           |
| `type`                                        | 上の3種類。取りうる値が固定なので enum で持つ |
| `actor_id`                                    | 起こした人。cascade                           |
| `mission_id` / `completion_id` / `post_id`    | 飛び先。種別によって使う列が違うので nullable |
| `read_at`                                     | null なら未読                                 |

- 一覧を引くために `(user_id, created_at)` の索引を張る。
- 参照先が消えたときに通知も消えるよう、飛び先の FK はすべて cascade。
- 通知の作成は、きっかけになった操作（参加 / 達成の記録 / リアクション）と
  同じトランザクションで行う。

## 動作確認の手順

（スキーマ・API・UI とも後続）

1. `bun run db:seed` でシードを流す。
2. 別のユーザーで、自分のやりたいことに参加する。作成者の通知一覧に1件届き、バッジが出る。
3. その通知をタップすると、そのやりたいことの画面に飛ぶ。バッジが減る。
4. 参加していない人を共同達成に入れると、その人に通知が届く。
5. 自分の投稿に自分でリアクションしても、通知は増えない。
