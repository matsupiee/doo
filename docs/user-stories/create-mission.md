# やりたいことを登録する

> ステータス: スキーマ済み / API・UI は後続

## ストーリー

**ユーザー** として、
**自分のやりたいことを登録しておきたい**。
そうすれば、**思いついたときに書き留めて、あとから達成を記録できる**し、
**同じことをやりたい人が見つけて一緒にやれる**。

## 受け入れ条件

- 作成画面で **タイトル** を入れるだけで登録できる。説明（`description`）は任意。
- 登録したやりたいことの作成者は自分（`mission.creator_id`）になる。
- タグは任意で複数付けられる → [やりたいことにタグをつける](./mission-tags.md)
- 登録した時点では **達成は0件**。達成の記録は
  [達成を記録する](./record-completion.md) の導線から行う。
- プロフィールの「やりたいこと」に、自分が作ったものが新しい順に並ぶ。
- 他の人のやりたいことは一覧から見えて、そこから join できる
  → [他の人のやりたいことに join する](./join-mission.md)
- 「渡す相手を選ぶ」「リレーで回す」は**廃止**した。誰かに割り当てる導線も、
  受け取る側のインボックスも無い。やりたいことは登録した本人のもので、
  他の人は自分から join する。

## データの持ち方

| 表                    | 役割                                        |
| --------------------- | ------------------------------------------- |
| `mission`             | やりたいこと本体（`title` / `description` / `creator_id`） |
| `mission_tag`         | 付けたタグ（自由入力、`(mission_id, title)` で一意）        |
| `mission_participant` | そのやりたいことを「やる」人                                |

作成者が自動的に `mission_participant` の行を持つかは **未決**
（[ADR の積み残し](../adr/2026-09-08-mission-join-and-shared-completion.md)）。
持たせない場合、「作ったが自分ではやらない」やりたいことが参加者0人で存在しうるので、
その見え方を決める必要がある。

## 動作確認の手順

（API・UI は後続。現時点ではスキーマのみ）

1. `bun run db:seed` でシードを流す。
2. 作成タブでタイトルだけ入れて登録する。
3. プロフィールの「やりたいこと」に、いま登録したものが並ぶ。
4. 達成が0件なので、達成一覧には何も出ない。
