# 作成の入口をホーム右上の ＋ 1 か所にまとめる

- 日付: 2026-09-09
- ステータス: 採用（実装済み）

## 背景

やりたいことを登録できる場所が 4 か所に散らばっていた。

1. ボトムタブ中央の ＋ タブ（`app/(tabs)/create.tsx`）
2. プロフィール右上の ＋ アイコン
3. プロフィールの「やりたいことを登録」ボタン
4. フィードが空のときの「やりたいことを登録する」リンク

どれも同じ `/create` に飛ぶだけで、増やした分だけ「どこから登録するのが正しいのか」が
分かりにくくなっていた。さらに「達成」のほうは、やりたいことの詳細を開いて
ヘッダーの ＋ を押す、という別の導線にしか置かれておらず、
登録と達成という対になる操作が別々の場所にあった。

## 決定

作成の入口をホーム（フィード）ヘッダー右上の ＋ 1 か所に集約し、
そこから出るシートで「やりたいことの登録」と「達成」を選ばせる。

### ＋ とシートは 1 つのコンポーネントに閉じる

`components/ig/create-menu.tsx` の `CreateMenuButton` が、＋ ボタンと
シートの状態の両方を持つ。呼ぶ側は置くだけでよく、レイアウトと画面のあいだで
開閉状態を持ち回す仕組みは要らない。

ただし `Tabs` の `headerRight` の中には置けない。react-navigation の
ヘッダーはネイティブ側の別の階層に描かれるので、そこから `Modal` を出しても
画面に現れず、＋ を押しても何も起きない（タップ自体は届いている）。
そのためホームのヘッダーは `headerShown: false` にして画面の中で組み、
＋ とシートを同じツリーに入れる。プロフィールはもともとこの形だったので、
タブの 2 画面ともヘッダーを自前で持つことになり、かえって揃った。

### 達成は、シートの中身を差し替えて対象を選ばせる

達成はどのやりたいことに対する達成かが決まらないと投稿できない。
シートを重ねると iOS で `Modal` の出し入れが重なるので、モーダルは 1 枚のままで、
中身を「2 択のメニュー」から「参加しているやりたいことの一覧」に差し替える。
選ぶと `/mission/[missionId]` に `compose=1` を付けて遷移し、
詳細画面が投稿シートを開いた状態で立ち上がる。投稿フォーム自体は
すでに詳細画面にあるものをそのまま使い、二重に持たない。

### 登録画面はタブから外して、スタックの画面にする

`app/(tabs)/create.tsx` を `app/create.tsx` に移し、ルートの `Stack` に
「やりたいことの登録」として登録する。＋ タブが消えるので、タブは
ホームとプロフィールの 2 つになる。登録が終わったら `router.push` ではなく
`router.replace` で詳細画面に入れ替え、戻るとホームに戻るようにする。

### ヘッダーの見出しを消す

ホーム左上のワードマークと、プロフィール左上のアカウント名を消す。
アカウント名はプロフィール本文にも出ているので、ヘッダーからは重複が減る。
ワードマークはサインイン前の画面（`app/(auth)/`）では引き続き使う。

## 却下した選択肢

- ＋ タブを残したまま、ほかの 3 か所だけを消す。
  タブは常に見えている一方で、シートを出す起点としては置き場所が悪い。
  Instagram も作成はシートで、タブからもヘッダーからも同じシートが出る。
  入口を 1 つにするなら、タブとヘッダーの二重化はやめたほうが分かりやすい。
- 達成用の画面（`/complete`）を新しく作り、そこで対象を選ばせる。
  やりたいことを選ぶだけのために画面を 1 枚増やすことになる。
  選んだ先で結局は詳細画面の投稿シートを開くので、シートの中で選べば足りる。
- 達成の投稿フォームをシートの中に持たせる。
  詳細画面の投稿フォーム（メディアの種類・アップロード・一緒に達成した人）を
  もう一組作ることになり、片方だけ直す事故が起きる。

## 影響

- タブは `index` と `profile` の 2 つになった。`app/(tabs)/create.tsx` は
  `app/create.tsx` に移動している。
- `Tabs` の `headerShown` は `screenOptions` で `false` にした。
  ヘッダーの色・線の指定はどちらの画面も使わなくなったので消し、
  `(tabs)/_layout.tsx` に残るのはタブバーの見た目だけになった。
- `/create` に飛ぶコードは `create-menu.tsx` だけになった。
  プロフィールとフィードからは登録ボタンが消え、案内文だけが残る。
- `mission/[missionId]` は `compose` パラメータを受け取るようになった。
  `compose=1` のときだけ投稿シートを開いた状態で始まる。
- 詳細画面ヘッダーの ＋（投稿する）はそのまま残している。
  そのやりたいことを見ている最中の投稿は、ホームに戻らずできたほうがよい。
