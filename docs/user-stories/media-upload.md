# 達成の証拠として写真・動画をアップロードする

**As a** ミッションを受け取ったユーザー
**I want** 手元の写真や動画をそのままアプリから投稿したい
**So that** どこかに画像をアップして URL を取ってくる手間なしに、達成を証明できる

## 背景

以前は「写真のURL」テキスト欄に外部の URL を貼るしかなく、
実質的にミッションをクリアできない状態だった。
実体は Cloudflare R2 に置き、投稿には公開 URL だけを保存する。

## シナリオ

### 写真をアップロードして達成を投稿する

1. インボックスからミッションを開く（`/mission/[assignmentId]`）
2. 「達成の証明」で **写真** を選ぶ
3. **ライブラリから選ぶ** か **撮影する** をタップする
4. 初回はフォトライブラリ／カメラの許可を求められ、許可すると選択画面が開く
5. 選ぶとサムネイルが出て「写真をアップロード中…」が表示される
6. 完了すると「写真をアップロードしました」に変わり、**達成として投稿する** が押せるようになる
7. 投稿すると、ホームのフィードにその写真が並ぶ

### 動画も同じ流れで投稿できる

- **動画** を選ぶと、ライブラリは動画だけを、カメラは録画モードで開く
- アップロード後はフィードに動画の URL が出る（プレイヤーは未実装）

### アップロードせずには投稿できない

- 写真／動画を選んでいる間は、アップロードが完了するまで **達成として投稿する** は押せない
- 写真 → 動画 のように種類を切り替えると、前の種類でアップロードしたファイルは破棄され、
  もう一度選び直す必要がある

### 失敗したときに理由が分かる

| 状況 | 表示 |
| --- | --- |
| 写真が 10MB を超えている | 「ファイルが大きすぎます（最大 10MB）」 |
| 動画が 100MB を超えている | 「ファイルが大きすぎます（最大 100MB）」 |
| 許可していない形式（PDF など） | 「Unsupported content type. …」 |
| フォトライブラリ／カメラの許可がない | 「写真へのアクセスが許可されていません」 |
| サーバーに R2 が未設定 | 「アップロード先が未設定です。サーバーの R2 設定を確認してください」 |
| R2 への PUT が失敗 | 「アップロードに失敗しました (ステータスコード)」 |

## 満たすべき条件

- サインインしていないと presigned URL は発行されない（`UNAUTHORIZED`）
- オブジェクトキーは **サーバーがセッションのユーザー ID から組み立てる**。
  クライアントは自分のキーを指定できないので、他人の領域に上書きできない
- キーには cuid2 が入るので、公開バケットでも他人の投稿を推測してたどれない
- presigned URL の有効期限は 5 分
- `Content-Type` は署名に含まれるので、許可した形式と違うものは R2 側で弾かれる
