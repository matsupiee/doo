# やりたいこと画面から操作する

> ステータス: 実装済み。画面まわりのみで、API の追加はない。

## ストーリー

やりたいことの参加者として、
1つの画面の上部から、投稿・シェア・削除・参加者の確認をすぐに呼び出したい。
そうすれば、本文の下までスクロールしなくても、その場でやりたい操作にたどりつける。

## 動作確認の手順

1. `bun run db:seed` でシードを流す。
2. 「やりたいこと」を開く。
   - 丸いアイコンの右にタイトルが見出しとして出る。
   - 見出しの下の行に、達成数と参加数が横に並ぶ。
   - 説明・ハッシュタグ・登録した人は、見出しの下のブロックに続く。
3. ヘッダー右の3点リーダーを押す。
   - 下からメニューのシートが出る。
   - 作成者には「削除」が出る。押すと確認のダイアログを経て削除される。
   - 作成者以外の参加者には「抜ける」が出る。
   - 参加していない人には3点リーダー自体が出ない。
4. ヘッダーの + ボタンを押す。
   - 下から投稿のシートが出る。
   - シートの中でテキスト・写真・動画を選び、一緒に達成した人も指定できる。
   - 「達成として投稿する」で達成を記録し、シートが閉じて入力内容が消える。
   - 「進捗として投稿する」でも同じようにシートが閉じる。
   - → [達成を記録して投稿する](./record-completion.md)
   - 参加していない人には + ボタンが出ない。
5. + の右のシェアボタンを押す。
   - 端末の共有シートが開く。
   - 共有する文にタイトル・ハッシュタグ・`doo://mission/<id>` が入る。
6. 参加者のアイコンが横に並ぶ行の右端にあるシェブロンを押す。
   - 下から参加者一覧のシートが出る。
   - 登録した人には「登録した人」と表示され、アイコンにリングが付く。
   - 行を押すと、その人のプロフィールに移動してシートが閉じる。
   - → [他の人のやりたいことに参加する](./participate-in-mission.md)
7. 参加していない状態で開く。
   - 「参加する」ボタンだけが本文の上に出る。
   - 参加すると、ヘッダーに + ボタンと3点リーダーが出る。

## データの持ち方

- この画面の操作は `mission.get` の戻り値だけで決まる。テーブルは追加しない。
  - `isCreator` が3点リーダーの「削除」を出すかどうかを決める。
  - `isParticipant` が + ボタンと「抜ける」を出すかどうかを決める。
  - `participants` と `completions` の件数が、見出しの下の数字になる。

## 対応するテスト

画面が使う `mission.get` の戻り値は `packages/api/test/mission.test.ts` が守る。画面の操作
そのものは iOS シミュレータでの手動確認で担保する。

```bash
bun run test
```
