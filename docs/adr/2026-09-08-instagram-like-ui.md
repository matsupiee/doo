# UI を Instagram に寄せて作り直す

- 日付: 2026-09-08
- ステータス: 採用（実装済み）

## 背景

doo は「やりたいことを登録して、達成したら投稿する」写真・動画中心の SNS で、
やることの並びは Instagram とほぼ同じになる。ところが画面のほうは
heroui-native の `Card` を縦に積む汎用的な作りで、投稿は角丸のカードに小さく収まり、
アプリ全体の見た目が写真 SNS というより設定画面に近かった。

見慣れた SNS と同じ形にすれば、初めて開いた人でも説明なしに操作できる。
そこで見た目とレイアウトを Instagram に合わせる。

## 決定

配色・余白・画面構成の3つを Instagram に合わせる。

### 配色はテーマトークンの上書きで入れる

各コンポーネントに色を直書きせず、`apps/native/global.css` で
heroui-native のトークン（`--background` `--foreground` `--border` など）を
Instagram の値に差し替える。ライトは白地に `#dbdbdb` の細い線、
ダークは真っ黒地に `#262626` の線、アクセントは `#0095f6`、ハートは `#ed4956`。

heroui-native のコンポーネント（`Spinner` `useToast` など）を使い続けても
自動で新しい配色になり、ライトとダークの切り替えも1か所で完結する。

### カードをやめて、全幅と細い線で区切る

投稿は画面幅いっぱいの正方形にして、カードの角丸と影をなくす。
区切りは影ではなく 0.5px の線だけにする。

写真のない投稿（テキストだけの達成・進捗）は、Instagram のストーリーの文字投稿に
ならって、投稿 ID から決まるグラデーションの色面に文字を載せる。
グラデーションは `expo-linear-gradient` を足さず、すでに入っている
react-native-svg で描く（`components/ig/gradient.tsx`）。

### doo の概念を Instagram の部品に対応させる

新しい概念を足すのではなく、既存の概念を Instagram の見慣れた部品に載せる。

| doo の概念                 | Instagram での置き場所                       |
| -------------------------- | -------------------------------------------- |
| 投稿につくやりたいこと     | ユーザー名の下の位置情報の行                 |
| タグでの絞り込み           | フィード上部のストーリートレイ               |
| タグ                       | キャプションの下の青いハッシュタグ           |
| 達成・進捗の区別           | 写真の右上の小さなしるし                     |
| 共同達成                   | 写真の左下のタグ付けのしるし                 |
| 達成の一覧                 | プロフィールの3列グリッド                    |
| 参加しているやりたいこと   | プロフィールのハイライト                     |
| やりたいことへの参加       | プロフィールのフォローボタン                 |
| やりたいことの詳細         | プロフィール（アイコン・件数・説明・グリッド）|

写真のダブルタップでいいねが付く動作も入れる。すでに付いている場合は外さない。

## 却下した選択肢

- heroui-native の `Card` `Button` `Chip` のまま色だけ変える。
  角丸と影と内側の余白がライブラリ側で決まっていて、全幅の投稿と
  1px 隙間のグリッドが作れない。見た目の中心がカードのままになる。
- `expo-linear-gradient` を入れる。
  グラデーションを使うのは文字投稿の背景とアバターのリングだけで、
  同じことが react-native-svg でできる。依存を1つ増やす理由が弱い。
- Instagram の Billabong に似た書体をフォントファイルとして同梱する。
  ロゴのためだけにフォントを積むと起動が重くなるので、
  端末にある筆記体寄りのセリフ体（iOS は Snell Roundhand）を使う。

## 影響

- 画面はすべて書き直しになった。`components/ig/` に Instagram 由来の部品
  （アバター・グラデーション・グリッド・プロフィールの件数とタブ）を置き、
  各画面はそれを組み合わせる。
- 汎用の `Container` は使う画面がなくなったので削除した。
- タグの `Chip` は青いハッシュタグの文字に変わった。`TagChips` の名前は
  そのままだが、中身はチップではない。
- 画面の切り替え（サインアウト・テーマ）はプロフィール右上のハンバーガーから
  `Alert` で出す。Instagram の設定メニューと同じ置き場所になる。
