# フィードをタグで絞り込む

> ステータス: スキーマ済み / API・UI は後続

## ストーリー

フィードを眺める人として、タグでフィードを絞り込みたい。
そうすれば、いま気になっている種類の達成・進捗だけを追える。

## 動作確認の手順

1. `bun run db:seed` でシードを流す。
2. ホームのフィードを開く。
   - すべてのユーザーの投稿が並ぶ。非公開の投稿は存在しない。
   - フィード上部に、タグのチップが横スクロールで並ぶ。
   - 並ぶのは固定のカテゴリ一覧ではなく、実際に使われているタグ。
   - 何も選んでいないので全件表示になる。
3. タグのチップを1つ選ぶ。
   - そのタグが付いた「やりたいこと」の投稿だけが残る。
   - もう一度タップすると解除され、全件に戻る。
4. タグを2つ選ぶ。
   - どれか1つでも一致すれば表示される（OR）。
   - 複数のタグを持つ「やりたいこと」の投稿が複数チップに一致しても、1回だけ表示される。
5. 使われていないタグを選ぶ。
   - 「このタグの投稿はまだありません。」と出る。
6. 絞り込んだ状態で、フィードを下までスクロールする。
   - ページング（`nextCursor`）と併用しても壊れない。

## データの持ち方

- 投稿（`post`）は必ず1つの `mission` に紐づく。
  - 投稿そのものにはタグを持たせない。
- 絞り込みは `post` → `mission` → `mission_tag.title` を辿って行う。
  - 照合は完全一致。表記ゆれの吸収は [やりたいことにタグをつける](./mission-tags.md) の未決事項。
  - 1件の投稿が複数タグに一致しても重複させない。
