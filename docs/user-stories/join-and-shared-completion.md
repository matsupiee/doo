# 他の人のやりたいことに join して、共同達成として記録する

## ストーリー

**ユーザー** として、
他の人が登録した「やりたいこと」を見て **自分も一緒にやりたい**。
そうすれば、達成したときに **一緒にやった人と共同の達成として記録できる**。

## 受け入れ条件

- 他の人のやりたいことに **自分から join できる**。承認は要らず、その場で参加者になる。
- 同じやりたいことに **同じ人が二重に並ばない**。
- 達成を記録すると **必ず投稿が1件作られる**。投稿のない達成は存在しない。
- 達成には **一緒に達成した人を複数人ぶら下げられる**。1人だけなら個人達成として記録される。
- 達成日時は、記録した日時とは別に指定できる（あとから「先週やった」を登録できる）。
- 1つの投稿が2つの達成を指すことはない。
- プロフィールから、その人が達成したこと（個人・共同の両方）を一覧できる。
- 達成していなくても、進捗報告として投稿できる。

## 動作確認の手順

（API・UI は後続。本 PR はスキーマと設計のみ）

1. `bun run db:seed` でシードを流す。
2. 他のユーザーのやりたいことを開いて join し、参加者に自分が並ぶ。
3. もう一度 join しても参加者が増えない。
4. 達成を記録し、一緒に達成した人を1人選ぶ。フィードに投稿が出て、両方のプロフィールの
   達成一覧に同じ達成が並ぶ。
5. 1人だけで達成を記録した場合は、個人達成として自分のプロフィールにだけ並ぶ。
