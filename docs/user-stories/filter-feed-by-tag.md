# フィードをタグで絞り込む

> ステータス: スキーマ済み / API・UI は後続

## ストーリー

**フィードを眺める人** として、
**タグでフィードを絞り込みたい**。
そうすれば、**いま気になっている種類の達成・進捗だけ**を追える。

## 受け入れ条件

- ホームのフィード上部に、タグのチップが横スクロールで並ぶ。
  並ぶのは固定のカテゴリ一覧ではなく、**実際に使われているタグ**。
- チップをタップすると、そのタグが付いたやりたいことの投稿だけになる。もう一度タップで解除。
- 複数選んだときは **OR**（どれか1つでも一致すれば表示）。
- 複数のタグを持つやりたいことの投稿が、複数チップに一致しても **1回だけ** 表示される。
- 何も選んでいないときは全件表示。
- 一致するものが無いときは「このタグの投稿はまだありません。」と出る。
- 絞り込みはページング（`nextCursor`）と併用しても壊れない。
- タグの照合は **完全一致**。表記ゆれの吸収は
  [やりたいことにタグをつける](./mission-tags.md) の未決事項。

## データの持ち方

投稿（`post`）は必ず1つの `mission` に紐づく。絞り込みは
`post → mission → mission_tag.title` を辿って行う。投稿そのものにはタグを持たせない。

## 動作確認の手順

（API・UI は後続。現時点ではスキーマのみ）

1. `bun run db:seed` でシードを流す。
2. ホームでタグのチップを1つ選ぶと、そのタグが付いた投稿だけが残る。
3. 使われていないタグを選ぶと空表示になる。
4. 選択を解除すると全件に戻る。
5. タグを2つ選ぶと、どちらかに一致する投稿が重複なしで並ぶ。
