# 渡す相手を決めずにミッションだけ作る

## ストーリー

**出題者** として、
**渡す相手を決めずにミッションだけ作っておきたい**。
そうすれば、**思いついたときに書き留めて、渡す相手はあとから決められる**。

## 受け入れ条件

- 作成画面で「自分にも渡す」も相手も選ばずに作成できる。ボタンの文言は
  相手がいないとき「ミッションを作る」、いるとき「ミッションを渡す」。
- 相手が0人で作られたミッションは、assignment が0件で保存される。
- **リレーは例外**: リレーは最初に走る人が必要なので、相手が0人だと `BAD_REQUEST`。
  UI 側でも「リレーは最初に走る人が必要です」と出して送信をブロックする。
- プロフィールの「出したミッション」に「まだ誰にも渡していません」として並ぶ。
- そのカードから、あとで「誰かに渡す」（相手を選ぶ）か「自分でやる」ができる。
- あとから渡す (`mission.assign`) の制約:
  - ミッションの作成者のみ実行できる（他人のものは `NOT_FOUND`）。
  - すでに持っている人には二重に渡さない（その分は追加されず、件数にも入らない）。
  - 存在しないユーザーを指定すると `BAD_REQUEST`。
  - リレーのミッションは対象外（クリアした人が次に渡す仕組みのため `BAD_REQUEST`）。

## 動作確認の手順

1. 作成タブでミッション名だけ入れ、相手を選ばずに「ミッションを作る」。
2. プロフィールの「出したミッション」に「まだ誰にも渡していません」と出る。
3. 「誰かに渡す」から相手を選んで渡すと、相手の「来ているミッション」に現れる。
4. 同じ相手にもう一度渡しても増えない。

## 対応するテスト

`packages/api/test/mission.test.ts` の `mission.create — nobody assigned` /
`mission.assign`
