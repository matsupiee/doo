# やりたいことにタグをつける

> ステータス: スキーマ済み / API・UI は後続

## ストーリー

**やりたいことを登録する人** として、
**タグを複数つけたい**。
そうすれば、**見る人も一緒にやりたい人も、どんな種類のやりたいことかひと目でわかる**。

## 受け入れ条件

- 作成画面で **自由入力のタグ** を付けられる。固定のカテゴリ一覧（料理 / 運動 / …）は
  **廃止**した。選択肢から選ぶのではなく、自分で言葉を書く。
- タグは **任意**。1つも付けずに登録できる。
- タグは **複数** 付けられる。同じやりたいことに **同じタグを二重に保存しない**
  （`(mission_id, title)` の unique index で DB が弾く）。
- 空文字・空白だけのタグは受け付けない（`BAD_REQUEST`）。
- 付けたタグは、以下すべてで表示される:
  - プロフィールの「やりたいこと」
  - やりたいことの詳細
  - ホームのフィードの投稿カード
- タグを付けていないやりたいことは、API では `[]`（`null` ではない）が返り、
  UI ではバッジが出ない。

## データの持ち方

`mission_tag`（`mission_id` / `title`）に1タグ1行。旧 `mission_category` の
固定 enum は廃止した。

## 未決

自由入力にしたことで **表記ゆれ**（「おでかけ」「お出かけ」「外出」）が起きる。
候補のサジェストか正規化のルールが要る
（[ADR の積み残し](../adr/2026-09-08-mission-join-and-shared-completion.md)）。
それまでは [タグでの絞り込み](./filter-feed-by-tag.md) は完全一致で動く。

## 動作確認の手順

（API・UI は後続。現時点ではスキーマのみ）

1. `bun run db:seed` でシードを流す。
2. 作成タブでタイトルを入れ、タグを2つ書いて登録する。
3. プロフィールの「やりたいこと」に、書いた2つのバッジが出ている。
4. 同じタグをもう一度足しても、バッジは増えない。
5. タグを1つも付けずに登録したものには、バッジが出ない。
