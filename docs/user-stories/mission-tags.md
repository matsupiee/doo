# やりたいことにタグをつける

> ステータス: スキーマ済み / API・UI は後続

## ストーリー

やりたいことを登録する人として、タグを複数つけたい。
そうすれば、見る人も一緒にやりたい人も、どんな種類のやりたいことかひと目でわかる。

## 動作確認の手順

1. `bun run db:seed` でシードを流す。
2. 作成タブでタイトルを入れ、タグを2つ書いて登録する。
   - タグは自由入力で書く。固定のカテゴリ一覧（料理 / 運動 / おでかけ など）は廃止した。
   - タグは複数付けられる。
3. プロフィールの「やりたいこと」を開く。
   - 書いた2つのバッジが出ている。
   - タグは「やりたいこと」の詳細と、ホームのフィードの投稿カードにも出る。
4. 同じタグをもう一度足す。
   - 二重には保存されない。バッジも増えない。
5. 空文字や空白だけのタグを付けて登録する。
   - API が `BAD_REQUEST` を返す。
6. タグを1つも付けずに登録する。
   - 登録できる。タグは任意。
   - API では `[]` が返る。`null` ではない。
   - UI ではバッジが出ない。

## データの持ち方

- タグは `mission_tag` に1タグ1行で持つ。
  - `mission_id` と `title` を持つ。`title` は自由入力の文字列。
  - 旧 `mission_category` の固定 enum は廃止した。
- `(mission_id, title)` に unique index を張る。
  - 同じ「やりたいこと」に同じタグが二重に入ることを DB レベルで防ぐ。
- 絞り込みのために `title` にも索引を張る。
  - → [フィードをタグで絞り込む](./filter-feed-by-tag.md)
