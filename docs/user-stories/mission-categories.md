# ミッションにカテゴリをつける

## ストーリー

**出題者** として、
ミッションを作るときに **カテゴリを複数つけたい**。
そうすれば、受け取った人も見る人も **どんな種類のミッションなのかひと目でわかる**。

## 受け入れ条件

- ミッション作成画面に、固定のカテゴリ一覧（料理 / 運動 / おでかけ / 学び / つくる / ネタ / 暮らし / その他）が並ぶ。
- カテゴリは **任意**。1つも選ばずに作成できる。
- カテゴリは **複数選べる**。同じカテゴリを二重に保存しない。
- スキーマにない値は API が弾く（`BAD_REQUEST` / バリデーションエラー）。
- 付けたカテゴリは、以下すべてで表示される:
  - プロフィールの「来ているミッション」
  - プロフィールの「出したミッション」
  - ホームのフィードの投稿カード
  - リレー詳細画面
- カテゴリを付けていないミッションは、API では `[]`（null ではない）が返り、UI ではバッジが出ない。

## 動作確認の手順

1. `bun run db:seed` でシードを流す。
2. 作成タブでミッション名を入れ、カテゴリを2つ選んで作成する。
3. プロフィールの「出したミッション」に、選んだ2つのバッジが出ている。
4. カテゴリを1つも選ばずに作ったミッションには、バッジが出ない。
