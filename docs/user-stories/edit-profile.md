# プロフィールを編集する

> ステータス: 実装済み。`user` テーブルに `bio` を足し、`user.updateProfile` を追加した。

## ストーリー

doo のユーザーとして、
自分のアイコン画像・名前・自己紹介を、専用の画面でまとめて書き換えたい。
そうすれば、やりたいことに一緒に参加する人に、自分がどんな人かを伝えられる。

## 動作確認の手順

1. `bun run db:migrate` でマイグレーションを流し、`bun run db:seed` でシードを入れる。
   - シードの「あおい」と「はる」には自己紹介があり、「みお」と「れん」にはない。
2. 自分のプロフィールのタブを開く。
   - 名前の下に自己紹介が出る。書いていなければ、その行は出ない。
3. 「プロフィールを編集」を押す。
   - プロフィール編集の画面に移る。ヘッダーのタイトルは「プロフィールを編集」。
   - アイコン・名前・自己紹介に、いま保存されている内容が入っている。
   - ヘッダー右に「完了」が出る。
4. 丸いアイコン、または「プロフィール写真を変更」を押す。
   - 下から「ライブラリから選ぶ」「写真を撮る」の選択肢が出る。
   - すでに写真があるときだけ「現在の写真を削除」も出る。押すとアイコンが頭文字に戻る。
   - 写真を選ぶとその場でアップロードが始まり、終わるまでアイコンの上にスピナーが出る。
   - アップロード中は「完了」を押せない。
   - → [写真と動画をアップロードする](./media-upload.md)
5. 名前を書き換える。
   - 40文字まで入る。
   - 空にすると「完了」を押せない。
6. 自己紹介を書き換える。
   - 200文字まで入る。入力欄の下に、いま何文字かが出る。
   - 空のままでも保存できる。
7. 「完了」を押す。
   - 「プロフィールを更新しました」と出て、プロフィールに戻る。
   - 戻った先のアイコン・名前・自己紹介が、いま保存した内容になっている。
   - 他の人から見たプロフィールにも、同じ内容が出る。
   - → [他の人のやりたいことに参加する](./participate-in-mission.md)
8. 「完了」を押さずに戻る。
   - 書きかけの内容は保存されない。もう一度開くと、保存済みの内容が入っている。

## データの持ち方

- アイコン・名前・自己紹介は `user` テーブルの `image`・`name`・`bio` に持つ。
  - `bio` は未入力なら null。空白だけを書いても null として保存する。
  - `image` はアップロード済みの公開 URL を入れる。画像そのものは R2 に置く。
  - `user` は better-auth が使う表なので、列を足すだけで作りかえはしない。
- `user.updateProfile` は3つをまとめて置き換える。
  - 画面はいつも3つとも今の値を送る。省いた項目は消したものとして null にする。
  - 書き換えられるのは自分のアカウントだけで、対象はセッションの user id で決まる。
