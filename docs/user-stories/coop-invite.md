# 他の人のミッションに「一緒にやろう」と声をかける

## ストーリー

**ユーザー** として、
他の人がやっているミッションを見て **「これ一緒にやらない？」と声をかけたい／自分から参加したい**。
そうすれば、ひとりで黙々とこなすのではなく **同じことを一緒にやる相手が見つかる**。

## 受け入れ条件

- ミッションの参加者は、そのミッションの作成者でなくても **他の人を誘える**。
  誘われた人には未クリアのミッションとして届き、**断ることもできる**。
- 誘うときに **一言メッセージを添えられる**（任意。空でも誘える）。
- 他の人のミッションに **自分から参加できる**。相手の承認は不要で、その場で自分のミッションになる。
- 同じミッションに **同じ人が二重に並ばない**。誘い済み・参加済みの相手を再度誘っても増えない。
- 一度断ったミッションに、あとからもう一度誘える。
- **リレーのミッションには横入りできない**（バトンはクリアした人が渡す）。
- ミッション詳細に「いまこれをやっている人」が並ぶ。
- 参加のしかたがバッジでわかる（自分で受けた / 指名 / ランダム / 一緒にやる）。

## 動作確認の手順

（API・UI は後続 PR。本 PR はスキーマと設計のみ）

1. `bun run db:seed` でシードを流す。
2. あるユーザーのミッションを開き、「一緒にやる」で参加する。
3. 参加者一覧に自分が並び、バッジが「一緒にやる」になっている。
4. 同じミッションでもう一度参加しても、参加者は増えない。
5. 参加したミッションから別のユーザーを一言つきで誘い、相手のプロフィールに届くことを確認する。
6. 相手が断ったあと、もう一度誘えることを確認する。
