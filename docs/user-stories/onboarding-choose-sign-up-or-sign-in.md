# アプリを開いたら新規登録とログインを選べる

## ストーリー

未ログインのユーザーとして、アプリを開いたときに「新規登録」と「ログイン」のどちらかを選びたい。
どちらを選んだのか分かる専用の画面で入力したいから。

## 受け入れ条件

- 未ログインでアプリを開くと、オンボーディング画面（アプリ名 + 説明 + 「新規登録」「ログイン」ボタン）が表示される。
- 「新規登録」を押すと新規登録画面（名前・メールアドレス・パスワード）に遷移する。
- 「ログイン」を押すとログイン画面（メールアドレス・パスワード）に遷移する。
- 新規登録画面とログイン画面はそれぞれ独立した画面で、フォームは同時に表示されない。
- 各画面の下部のリンクからもう一方の画面に切り替えられる。
- 各画面のヘッダーの「戻る」からオンボーディング画面に戻れる。
- 登録・ログインに成功すると、タブ（ホーム / 作成 / プロフィール）に切り替わる。
- サインアウトすると、オンボーディング画面に戻る。
- 未ログインの状態では、タブ・ミッション詳細・リレー詳細のいずれの画面にも到達できない。

## 実装メモ

- ルーティングは `apps/native/app/(auth)/` に分離し、`app/_layout.tsx` の `Stack.Protected`
  でログイン状態によって `(auth)` と `(tabs)` を出し分ける。
- 入力フォーム本体は `components/sign-in.tsx` / `components/sign-up.tsx`（画面側が見出しと
  リンクを持つ）。
