# フィードをカテゴリで絞り込む

## ストーリー

**フィードを眺める人** として、
**カテゴリでフィードを絞り込みたい**。
そうすれば、**いま気になっている種類の達成だけ**を追える。

## 受け入れ条件

- ホームのフィード上部に、カテゴリのチップが横スクロールで並ぶ。
- チップをタップすると、そのカテゴリの投稿だけになる。もう一度タップで解除。
- 複数選んだときは **OR**（どれか1つでも一致すれば表示）。
- 複数のカテゴリを持つミッションが、複数チップに一致しても **1回だけ** 表示される。
- 何も選んでいないときは全件表示。
- 一致するものが無いときは「このカテゴリの達成はまだありません。」と出る。
- 絞り込みはページング（`nextCursor`）と併用しても壊れない。

## 動作確認の手順

1. `bun run db:seed` でシードを流す。
2. ホームで「おでかけ」を選ぶと、れんの「知らない駅で降りて写真を撮る」だけが残る。
3. 「料理」を選ぶと、該当が無いので空表示になる。
4. 選択を解除すると全件に戻る。
