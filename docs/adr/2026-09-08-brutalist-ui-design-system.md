# アプリの見た目を、色の面と大きな角丸で組み立てる

- 日付: 2026-09-08
- ステータス: 承認

## 背景

画面は heroui-native の `Card` と `Button` をそのまま並べた作りで、
どの画面も同じグレーの箱が縦に並ぶだけだった。
やりたいことごとの区別も、達成と進捗の区別も、見ただけではつかない。

参考にしたデザイン（ほぼ黒の背景に、ビビッドな色の面と大きな角丸を置き、
見出しを太く大きく組む作り）に寄せるにあたって、
どこに何を持たせるかを決める必要があった。

## 決定

- 配色は `apps/native/global.css` で heroui-native のテーマ変数を上書きする。
  ダークは背景 `#0d0d0d`、ライトはクリーム `#efeae0`。
  ブランド色（violet `#6c5ce7` / coral `#f2543d` / yellow `#f7d046` /
  cream `#f2eee3` / ink `#101010`）はどちらのテーマでも同じ値を使う。
- 画面を組む部品は `apps/native/components/ui/` に置く。
  - `Panel` が色の面。`tone` でブランド色を選び、角丸は 28。
    面の色を React context で配り、`PanelTitle` などが自分の色を決める。
  - `ScreenHeader` が丸い戻るボタンと大きな見出し。ヘッダーは各画面が自分で描き、
    ナビゲーターのヘッダーは出さない。
  - `FloatingTabBar` が画面に浮かぶタブバー。選んでいるタブだけ violet の丸で塗る。
  - ほかに `ActionButton` `Pill` `Avatar` `StatTile` `RoundIconButton`。
- やりたいことの面の色は ID から決める（`toneForKey`）。
  同じやりたいことは、どの画面でもいつも同じ色になる。
- 背景に埋もれる色は、テーマで入れ替える。
  ダークでは cream、ライトでは ink を4色目に使う。
- 入力欄は heroui-native の `TextField` と `Input` のまま使う。
  上書きしたテーマ変数がそのまま効くので、見た目は揃う。

## 理由

- 面の色を context で配ると、面の上に置くテキストやボタンが色を引数で受け取らずに済む。
  黄色の面に白い文字を置くような取り違えが起きない。
- ID から色を決めるので、フィードで見たやりたいことと詳細画面のやりたいことが、
  色で結びつく。並べたときにも色が散る。
- 色をテーマ変数に集めたので、heroui-native の `Button` や `Input` を
  個別に着せ替えなくても、アプリ全体の色が揃う。

## 影響

- 全画面のレイアウトを書き直した（フィード・作成・プロフィール・他人のプロフィール・
  やりたいことの詳細・サインイン・サインアップ・404）。
  API とデータの持ち方は変えていない。
- `components/container.tsx` は、各画面が自分で余白とスクロールを持つようになったので消した。
- タブバーが画面に浮かぶので、スクロールする画面は下に 110 前後の余白を取る。
